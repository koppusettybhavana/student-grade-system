# Student Grade Management System (Python)

This is a simple **Python-based web application** developed using the **Flask framework** and **MySQL**.  
The project allows users to add student details and view student grades stored in a database.

## Technologies Used
- Python
- Flask (Python Web Framework)
- MySQL
- HTML

## Features
- Add student name, subject, and marks
- Store student data in MySQL database using Python
- Display all student records on the home page
